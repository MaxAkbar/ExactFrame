# ExactFrame 2.1.0

This release makes it easier to set up a recording, reuse a setup and choose the right application window. It brings together the improvements made since 2.0.0.

## Download and start

- [Windows x64 portable ZIP](https://github.com/MaxAkbar/ExactFrame/releases/download/v2.1.0/ExactFrame-2.1.0-win-x64-portable.zip) for Intel and AMD PCs.
- [Windows ARM64 portable ZIP](https://github.com/MaxAkbar/ExactFrame/releases/download/v2.1.0/ExactFrame-2.1.0-win-arm64-portable.zip) for Windows on Arm.

Extract the ZIP and open **ExactFrame.exe**. No installer or separate .NET or Windows App SDK installation is needed. Requires Windows 10 version 1809 or later; Windows 11 is recommended. The packages include the font license and instructions, with a separate SHA-256 checksum manifest attached to the release.

## What's new

- **Edit the frame directly.** Draw a region on screen, copy an existing window's bounds, drag the outline or resize with handles. Snapping and keyboard adjustments help with precise positioning.
- **Move additional frames directly.** Drag vertical, square and custom frames in the preview or on screen. Output width and height have sliders and exact-value boxes. Output previews help you compare crops, scaling and safe margins.
- **Send a frame to OBS.** Connect to OBS Studio on the same PC, preview a crop and apply it to an existing Display Capture item. Undo restores the previous crop and placement while the connection remains open.
- **Check your recording setup.** A guided checklist and copyable setup report help you test a saved clip. The floating controls now report and retry failed capture-exclusion requests.
- **Take profiles with you.** Export and import profiles, review display mappings, and update, rename or duplicate saved setups. Numbered shortcut assignments stay with their profiles when another profile is deleted.
- **Target the right window.** Narrow application matches by executable path, window title and window class. Review matching windows before applying a setup. Ambiguous matches require a selection instead of silently choosing the frontmost window.
- **Understand browser dimensions.** Labels distinguish physical capture pixels from Windows logical sizes. A browser guide explains how to check CSS viewport size, page zoom and device-pixel ratio separately.
- **Choose System, Light or Dark.** The Theme control applies immediately and remembers your choice independently of capture profiles. A compact layout and collapsible preview make controls easier to reach in smaller windows.
- **Find your way more easily.** The README now starts with downloads and a short recording walkthrough, with detailed feature and development guides linked separately.

The source also includes dependency lock files, a stable SDK pin, automated build and draft-release workflows, and repeatable Windows measurement and responsiveness checks.

## Before recording

ExactFrame prepares the recording area; your recorder captures the video. Save a short test clip to confirm the crop, output dimensions and whether guides are excluded.

**Hide from recorders** needs Windows 10 version 2004 or later and a compatible capture method. An accepted Windows API request does not prove that your recorder excludes the outline. If it appears in a saved clip, hide it before recording. The main ExactFrame window is not excluded.

## Known limitations

- No saved-recording compatibility pass has been established yet. Recorder methods, browser versions, display scaling and monitor transitions remain setup-specific; see the [compatibility matrix](../recording-compatibility.md).
- OBS integration requires OBS Studio 28 or later and supports visible, unlocked, unfiltered Display Capture items placed directly in a scene on this PC. Stop recording and streaming before applying or undoing. Window Capture, grouped sources and remote OBS are not supported.
- Browser sizing uses physical Windows measurements. CSS viewport size, browser zoom and device-pixel ratio are not measured by ExactFrame. Browser measurements depend on the page bounds exposed by the browser.
- ARM64 packages are cross-published; native ARM64 execution has not been verified. Clean-machine installation and the full browser/recorder matrix have not been verified.
- Native theme switching and compact layout have been checked. Actual contrast themes, enlarged Windows text, spoken screen-reader output and Windows-theme changes while System is selected still need acceptance checks.
- The release is unsigned, so Windows may show an unknown-publisher warning.

## Settings and help

Settings remain in `%LOCALAPPDATA%\ExactFrame\exactframe.db`, independently of the executable folder. If you enabled **Start with Windows**, keep the executable in a stable location. Press **F1** for Help, or use **Help → About → Copy system info** when [reporting a problem](https://github.com/MaxAkbar/ExactFrame/issues).
