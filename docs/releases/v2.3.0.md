# ExactFrame 2.3.0

Prepare recording setups with optional PowerToys tools. ExactFrame remains a standalone portable app: PowerToys is not required, normal startup does not check for it, and Command Palette sharing starts off.

## Download and start

- [Windows x64 portable ZIP](https://github.com/MaxAkbar/ExactFrame/releases/download/v2.3.0/ExactFrame-2.3.0-win-x64-portable.zip) for Intel and AMD PCs.
- [Windows ARM64 portable ZIP](https://github.com/MaxAkbar/ExactFrame/releases/download/v2.3.0/ExactFrame-2.3.0-win-arm64-portable.zip) for Windows on Arm.
- [Portable ZIP SHA-256 checksums](https://github.com/MaxAkbar/ExactFrame/releases/download/v2.3.0/SHA256SUMS.txt).

Extract the ZIP and open **ExactFrame.exe**. Windows 10 version 1809 or later is required; Windows 11 is recommended. No installer or separate .NET or Windows App SDK installation is needed. Existing settings and profiles stay in `%LOCALAPPDATA%\ExactFrame\exactframe.db`.

## Optional PowerToys tools

Open **Profiles → PowerToys (optional)** when you want to configure these tools:

- **Workspaces:** copy launch arguments for the active profile and add them to ExactFrame's entry in a PowerToys Workspace. Commands can apply a saved profile, show or hide the outline, copy bounds, and open the existing OBS or SnapStudio workflows. They also work from ordinary Windows shortcuts without PowerToys.
- **FancyZones:** apply a built-in or custom layout to FancyZones' first monitor, open its layout editor, or explicitly link a layout to a saved ExactFrame profile. A linked layout is requested before exact sizing. If it is unavailable, the frame profile still applies.
- **Awake:** request a 1–240 minute session with the display on. ExactFrame leaves existing Awake sessions alone and stops only the session it started. Its request ends when the timer expires or ExactFrame exits.
- **ZoomIt:** follow the guide for using ExactFrame's outline with ZoomIt's zoom, annotation and region recording. Region selection remains manual.

Profiles without layout links never discover or call PowerToys. Missing tools and optional-tool errors do not block normal framing, profiles, shortcuts, OBS or SnapStudio. The release adds searchable in-app Help and a [PowerToys setup guide](https://github.com/MaxAkbar/ExactFrame/blob/v2.3.0/docs/powertoys-integration.md).

## Command Palette companion — separate development download

The optional companion adds searchable profiles, outline controls, copy bounds, capture in SnapStudio, and access to OBS setup. Turn on **Share saved profiles** in ExactFrame after installing it. Sharing exposes a small local catalog of profile names, IDs, sizes and modes; the companion does not open the settings database or make network requests. Turning sharing off removes the catalog and invalidates previously displayed commands.

- [x64 development ZIP](https://github.com/MaxAkbar/ExactFrame/releases/download/v2.3.0/ExactFrame.CommandPalette-2.3.0-win-x64-development.zip).
- [ARM64 development ZIP](https://github.com/MaxAkbar/ExactFrame/releases/download/v2.3.0/ExactFrame.CommandPalette-2.3.0-win-arm64-development.zip).
- [Companion SHA-256 checksums](https://github.com/MaxAkbar/ExactFrame/releases/download/v2.3.0/POWERTOYS_SHA256SUMS.txt).

This companion requires **Windows 11, PowerToys Command Palette, and a PC already configured for development-package installation**. Extract the ZIP to a stable folder and run its **Install-Companion.ps1** in PowerShell, then reload Command Palette. The script registers the package; it does not enable Developer Mode, change certificate trust or install PowerToys. Unsigned MSIX files are also provided for packaging and development; they are not normal double-click installers. The portable ExactFrame app requires none of these steps.

## Checks and known limitations

Local validation passed 472 Core tests and 17 Windows/SDK tests, including missing PowerToys, profile-link fallback, sharing revocation, command quoting, and the extra argument Windows supplies during COM activation. Windows checks verified normal startup without a catalog, forwarding to the existing instance, accurate 2560 × 1440 bounds, and frame application after an optional FancyZones failure. The x64 companion was temporarily registered with the installed Command Palette; the host activated it and loaded its command provider successfully.

Both architectures build, and both companion packages pass MakeAppx validation. Native ARM64 execution, successful live layout changes and Awake sessions, and new saved-recording compatibility checks remain unverified. FancyZones actions target its first monitor; use its editor for other displays. Workspaces uses a configurable delay rather than an arrangement-complete notification. All downloads are unsigned. Existing recorder limitations still apply; check a saved test recording before a full take.
